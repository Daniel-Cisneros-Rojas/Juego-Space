## Descripción
Juego Space es un proyecto desarrollado en C#, inspirado en el clásico videojuego del mismo nombre. Utiliza librerías gráficas para dibujar en pantalla elementos a partir de vértices y líneas, ofreciendo una experiencia retro con estética de pixel art.

El jugador controla una nave espacial cuyo objetivo es eliminar oleadas de aliens que se aproximan. Existen tres tipos diferentes de enemigos, cada uno con animaciones de movimiento únicas, además de un jefe final que representa el mayor desafío.

# Características
Gráficos renderizados con librerías gráficas en C#.

Nave controlada por el jugador con mecánicas simples e intuitivas.

Tres tipos de aliens con animaciones en pixel art.

Jefe final con mayor dificultad y comportamiento especial.

Estilo retro basado en vértices y líneas.
